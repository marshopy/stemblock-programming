──────────────────────────────────────────────────────────
  COMMON ERRORS & FIXES
──────────────────────────────────────────────────────────

  Error: I click a drink button and nothing happens
      Fix: Check Gap 1 — did you delete 'pass' and write
           orders.append(drink)?  Did you call refresh_screen()?

  Error: "IndexError: pop from empty list"
      Fix: Check Gap 2 — the  .pop()  must be INSIDE
           if len(orders) > 0:   so it never runs on an empty list.

  Error: Total always says $0.00
      Fix: Check Gap 3 — did you delete the placeholder line
           return 0 ?  If it's still at the top, Python returns 0
           before your code even runs!

  Error: "TypeError: unsupported format string passed to NoneType.__format__"
      Fix: Gap 3 forgot to  return total .  A function with no
           return gives back None, and None can't be shown with :.2f

  Error: Total only shows the price of ONE drink
      Fix: Check your indentation in Gap 3:
           • total = 0  must be BEFORE the loop (not inside it)
           • return total  must be AFTER the loop (not inside it)

  Error: "TypeError: 'dict' object is not callable"
      Fix: You wrote  MENU(drink)  with round brackets.
           Dictionaries use SQUARE brackets:  MENU[drink]

  Error: "KeyError: 'Milk Tea 🧋'"
      Fix: Check Gap 4 — you tried  counts[drink] + 1  for a drink
           that isn't in the dictionary yet.  You need the
           if drink in counts: ... else: counts[drink] = 1  check.

  Error: "TypeError: argument of type 'NoneType' is not iterable"
      Fix: Gap 4 forgot to  return counts .

  Error: Every drink count is stuck at 1
      Fix: Check Gap 4 — in the  if  branch you need
           counts[drink] = counts[drink] + 1   (not  = 1)

  Error: Best seller is always the LAST drink, not the biggest
      Fix: Check Gap 5 — you must update  best_count  too,
           not just  best_drink .

  Error: "TypeError: '>' not supported between instances of 'str' and 'int'"
      Fix: Gap 5 compares the KEY (a drink name) instead of its
           count.  Use  counts[drink] > best_count ,
           not  drink > best_count .
