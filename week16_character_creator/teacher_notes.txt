── KEY TEACHING POINTS ─────────────────────────────────────

  • Truthy & falsy is the big "aha": bool("False"), bool("0")
    and bool("no") are all True.  Bug 4 and Step 10 both come
    back to this — never use bool() on user text.

  • try / except is NEW.  Read it as: "Try this.  If you get a
    ValueError, do this instead."  It beats .isdigit() because it
    handles negatives and decimals (with float()).

  • The validation loop (slide 14) is the pattern for all of
    Part 2:  while True  +  try / except  +  range check  +  return

  • {} is an empty DICT.  An empty set is set().  This trips
    students up in Step 6.

── STEP-BY-STEP: COMMON MISTAKES ──────────────────────────

  STEP 1  ask_int
    • try / except not lined up with each other → SyntaxError
    • The "Pick from…" print indented inside the if → never shows
    • No while True → asks once, then returns None on a bad answer

  STEP 2  ask_float
    • Forgot to change int() to float() → "1.5" is rejected

  STEP 3  ask_yes_no
    • Using bool(answer) instead of the sets → "no" gives True
    • Forgot .lower() → "Y" is rejected

  STEP 4  ask_name
    • name.isalpha() without removing spaces → "Ava Storm" rejected

  STEP 5  Ask the questions
    • Calling ask_int("Level? ") without low and high → TypeError:
      missing 2 required positional arguments

  STEP 6  Skills
    • skills = {} → that's a dict!  skills.add → AttributeError.
      It must be set()
    • split(",") gives " swim" with a space — that's why we .strip()

  STEP 7  Home
    • x, y, z = home → ValueError: not enough values to unpack

  STEP 8  The hero
    • Missing commas between lines inside { }
    • hero["stats"]["hp"] inside an f-string needs single quotes:
      {hero['stats']['hp']}

  STEP 9  Type check
    • EXPECTED values in quotes ("str") → isinstance error.
      The values are the TYPES themselves: str, int, float…
    • Live demo: change Step 5 to  speed = 2  → "✖ speed: NOT float"

  STEP 10  Save & load
    • bool(parts[3]) instead of  parts[3] == "True"  → a hero with
      no magic loads back as True.  Truthy & falsy again!
