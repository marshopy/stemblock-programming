# 🧋 STEM Block Programming Class

Python projects for Level 2 students.

## Week 12 — Boba Memory Match Game
A fill-in-the-gap tkinter card-matching game.
Students complete 4 functions to make the game fully playable.

**Files:**
- `game.py` — Student version (4 gaps to fill in)
- `solution.py` — Teacher solution (do not share with students)
- `hints.txt` — Tiered hints for each gap
- `README.txt` — How to open in Thonny + bonus challenges

## Week 13 — Boba Trivia Rush
A timed fill-in-the-gap tkinter quiz game: pick the right price before the timer runs out.
Students complete 6 functions. Introduces dictionaries, `random.sample` and a countdown timer.

**Files:**
- `game.py` — Student version (6 gaps to fill in)
- `solution.py` — Teacher solution (do not share with students)
- `hints.txt` — Tiered hints for each gap
- `README.txt` — How to open in Thonny + bonus challenges
- `teacher_notes.txt` — Per-gap teaching notes and common mistakes

## Week 14 — Pocket Pet (The Big Review)
A review of every Level 2 concept for new and returning students, followed by a
text-based virtual pet game the class builds together, step by step, in the Thonny Shell.
Covers variables, input, f-strings, if/elif/else, loops, functions, lists,
dictionaries, random, and classes.

**Files:**
- `pocket_pet_starter.py` — Student file (step headings only; type along with the slides)
- `pocket_pet.py` — Complete version
- `review_challenges.py` — Every review challenge from the slides, runnable to show the answers
- `README.txt` — How to open in Thonny, the 10 steps, bonus challenges
- `teacher_notes.txt` — Timing, answers, and common mistakes per step

## Week 15 — Boba Order Tracker
A code-together tkinter app focused on lists and dictionaries: track drink orders,
total sales, drink counts and the best seller. The teacher and class fill in
5 gaps together (I do → we do → you do).

**Files:**
- `game.py` — Student version (5 gaps to fill in)
- `solution.py` — Teacher solution (do not share with students)
- `hints.txt` — Tiered hints for each gap
- `README.txt` — How to open in Thonny + bonus challenges
- `teacher_notes.txt` — Quiz answers, how to run the code-together, per-gap notes
